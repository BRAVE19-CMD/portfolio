# Portfolio - Kezai Elhoues

Portfolio de **Data Analyst** presentant mes competences, experiences et projets en analyse de donnees.

## Technologies
- **Frontend :** React, TypeScript, Vite, Tailwind CSS, shadcn/ui
- **Data :** Python, Excel, Power BI, SQL

## Deploiement
```bash
pnpm install
pnpm run dev
```

## Structure
- `App.tsx` - Portfolio complet (7 sections)
- `components/` - Composants reutilisables
- `assets/` - CV, images, fichiers Excel
